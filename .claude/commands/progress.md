# Progress — оновити і показати звіт прогресу

Швидка перегенерація сторінки прогресу навчання.

## Що робити

1. **Синхронізуй `state.json` з реальністю.** Звірся з `PROGRESS.md`:
   - чи змінилась `current_phase`?
   - чи додались пройдені уроки (оновити `done`)?
   - чи розписалась раніше-порожня фаза на уроки (виставити `total`)?
   Якщо щось змінилось — онови `.claude/progress/state.json`.

2. **Перебудуй звіт:**
   ```bash
   python3 .claude/progress/build.py
   ```
   Скрипт сам пере-синхронізує `current_phase` для хука, порахує час з `events.jsonl`
   і перепише `report.html`.

3. **Покажи результат.** За замовчуванням — публікуй `report.html` артефактом
   (тим самим лінком, якщо він уже публікувався — знайти через Artifact list).
   Для публікації взяти з `report.html` лише `<title>` + `<style>` + вміст `<body>`
   (без doctype/html/head/body — обгортку артефакт додає сам). Або, якщо користувач
   просив локально — просто скажи шлях до `.claude/progress/report.html`.

## Коли викликати

Наприкінці уроку (після `/end-lesson`, коли `done`/`current_phase` могли змінитись),
або будь-коли коли хочеться глянути «скільки вже вклав і скільки лишилось».
