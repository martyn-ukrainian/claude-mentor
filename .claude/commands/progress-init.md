# Progress Init — розгорнути трекер прогресу

Одноразове (і безпечно повторюване) налаштування системи трекінгу часу й прогресу
навчання. Працює з будь-яким roadmap — читає його і будує структуру під нього.

## Що робити

1. **Прочитай `ROADMAP.md`** — витягни список фаз (заголовки `## Фаза N — Назва`).
   Для кожної: `id` (`phase-N`), `name` (`Фаза N`), короткий `subtitle` (2-4 слова з назви).

2. **Прочитай `PROGRESS.md`** — визнач для кожної фази:
   - `total` — скільки уроків заплановано (якщо фаза ще не розписана на уроки → `null`)
   - `done` — скільки реально пройдено (секції «Пройдено — Фаза N»)
   - `current_phase` — id фази, над якою працюємо зараз.

3. **Запиши `.claude/progress/state.json`** за схемою:
   ```json
   {
     "project": "<назва>",
     "generated_from": "ROADMAP.md + PROGRESS.md",
     "current_phase": "phase-N",
     "phases": [
       { "id": "phase-0", "name": "Фаза 0", "subtitle": "...", "total": 7, "done": 7 }
     ]
   }
   ```

4. **Переконайся що хук зареєстровано** у `.claude/settings.json` (UserPromptSubmit →
   `$CLAUDE_PROJECT_DIR/.claude/progress/track-time.sh`). Якщо файлу нема — створи.
   Якщо хук щойно додано — попередь користувача що він активується з наступної сесії
   Claude Code (хуки читаються на старті).

5. **Зроби скрипти виконуваними і збери звіт:**
   ```bash
   chmod +x .claude/progress/track-time.sh .claude/progress/build.py
   python3 .claude/progress/build.py
   ```

6. **(Опційно) бекфіл історії.** Якщо є глобальний prompt-tracker
   (`~/.claude/prompt-tracker/prompts.db`) — можна одноразово засіяти `events.jsonl`
   історичним часом цього проєкту, тегуючи фази за датами (див. README трекера).
   **Тільки якщо `events.jsonl` ще не існує** — бекфіл перезаписує файл, повторний
   запуск зітре історію, зібрану хуком. Без бекфілу трекер просто почне рахувати
   з нуля — це теж норм.

## Результат

`.claude/progress/report.html` — самодостатня сторінка: таймлайн часу по днях
(згруповано по фазах) + лоадер прогресу по роадмапу у відсотках. Відкривається як
файл, або публікується артефактом через `/progress`.
