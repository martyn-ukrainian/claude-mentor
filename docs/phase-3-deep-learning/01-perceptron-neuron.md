# 01 — Перцептрон: нейрон, шар, мережа, ручний backprop

## Що це

Найменша обчислювальна одиниця нейромережі (**нейрон**, або перцептрон) робить дві дії підряд:

1. **Зважена сума входів** — кожен вхід `x_i` множиться на власну вагу `w_i`, додається bias `b`: `z = w·x + b` (dot product, той самий, що з Фази 1)
2. **Активація** — нелінійна функція від `z`, наприклад sigmoid: `a = sigmoid(z)`

```python
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def neuron_forward(x, w, b):
    z = np.dot(x, w) + b
    return sigmoid(z)
```

Один нейрон з sigmoid — це буквально логістична регресія (Фаза 2): `w` = `.coef_`, `b` = `.intercept_`.

**Шар (layer)** — кілька нейронів паралельно, кожен зі своїми вагами, але дивляться на той самий вхід. Замість списку окремих `w`-векторів їх зручно скласти рядками в матрицю `W` (кожен рядок — ваги одного нейрона):

```python
def layer_forward(x, W, b):
    z = np.dot(W, x) + b   # порядок важливий: W @ x, не x @ W
    return sigmoid(z)
```

**Мережа (MLP)** — кілька шарів підряд, вихід одного шару стає входом наступного:

```python
hidden_output = layer_forward(x, W1, b1)
output = layer_forward(hidden_output, W2, b2)
```

## Для чого

Реальні нейромережі (розпізнавання зображень, LLM) — та сама конструкція: шар → шар → шар, тільки замість 2 нейронів у шарі — тисячі, і шарів не 2, а сотні. Ключова відмінність від класичного ML (Фаза 2): **hidden-шар сам формує нові ознаки з сирих даних під час навчання**, замість того щоб інженер вручну робив feature engineering (PCA, encoding).

## Розбір

### Чому активація обов'язкова

Без активації (тільки зважена сума) два шари підряд математично зводяться до одного:

```
z = w1*x           (шар 1, скаляр для простоти)
y = w2*z = w2*(w1*x) = (w2*w1)*x
```

Перевірка на числах: `w1=2, w2=3, x=5`. Послідовно: `z=2*5=10`, `y=3*10=30`. Заздалегідь перемножені ваги: `w2*w1=6`, `y=6*5=30` — той самий результат. Тобто скільки шарів не став, без активації мережа еквівалентна **одному** лінійному перетворенню. Активація (нелінійність) — це те, що робить кожен наступний шар справді новим, а не ще одним множником.

### Chain rule — основа backprop

Якщо `y = f(g(x))`, похідна: `dy/dx = f'(g(x)) * g'(x)` — перемножуєш похідні зовнішньої і внутрішньої функції.

Приклад: `y = (2x+1)²`, `g(x)=2x+1`, `f(u)=u²`. При `x=1`: `g(1)=3`, `f'(u)=2u → f'(3)=6`, `g'(x)=2`. `dy/dx = 6*2 = 12`.

### Ручний вивід градієнта для одного нейрона

Задача: один нейрон, `z = wx+b`, `a = sigmoid(z)`, loss `L = (a-y)²` (MSE на одному прикладі). Потрібен `dL/dw` — як міняти `w`, щоб зменшити `L`.

Ланцюжок залежностей: `L → a → z → w`. Chain rule розбиває на три множники:

| Похідна | Формула | Звідки |
|---|---|---|
| `dL/da` | `2(a-y)` | правило степеня: `L=(a-y)²`, `u=(a-y)`, `d(u²)/du=2u`, `du/da=1` |
| `da/dz` | `sigmoid(z)*(1-sigmoid(z))` | відома властивість похідної sigmoid |
| `dz/dw` | `x` | `z=wx+b`, похідна лінійної функції по `w` = коефіцієнт при `w` |

Разом: `dL/dw = 2(a-y) * a(1-a) * x`. Аналогічно `dz/db = 1` (бо `b` входить у `z` без коефіцієнта), тому `dL/db = 2(a-y) * a(1-a)`.

### Градієнтний спуск на цій формулі

```python
x, y = 2.0, 1.0
w, b = 0.0, 0.0
lr = 0.1

for i in range(50):
    z = w * x + b
    a = sigmoid(z)
    L = (a - y) ** 2

    dL_dz = 2 * (a - y) * a * (1 - a)
    dL_dw = dL_dz * x
    dL_db = dL_dz * 1

    w -= lr * dL_dw
    b -= lr * dL_db
```

Результат: `loss` спадає з `0.25` (старт, `a=0.5` — модель каже "50 на 50") до `0.019` за 50 ітерацій — модель поступово вчиться давати `a` ближче до правильної відповіді `y=1`.

### Що таке градієнт насправді

Градієнт — не абстракція, а вимірювання: "якщо трошки посунути `w`, наскільки і в який бік зміниться `loss`". Перевірка через finite differences (чисельний градієнт) дає те саме число, що аналітична формула:

```python
L0 = loss(w=0)          # 0.25
L1 = loss(w=0.0001)     # 0.24995
numeric_grad = (L1 - L0) / 0.0001   # -0.5
analytic_grad = 2*(a-y)*a*(1-a)*x   # -0.5, теж саме
```

Це "нахил кривої `loss(w)` у поточній точці" — уяви `loss` як висоту пагорба залежно від `w`. Градієнт каже, в який бік іти вниз (напрямок) і наскільки круто (сила кроку). Далеко від мінімуму нахил крутий → великі кроки; близько до мінімуму — пологий → маленькі кроки, самокорекція без ручного налаштування.

Модель не бачить всю форму кривої заздалегідь (як під час навчання ми не знаємо оптимальні ваги наперед) — вона намацує шлях вниз крок за кроком, дивлячись тільки на локальний нахил у поточній точці.

## Gotchas

- **Порядок множення матриці й вектора має значення.** `W @ x` ≠ `x @ W` (та сама некомутативність матриць з Фази 1) — для шару правильно `np.dot(W, x)`, не навпаки.
- **Не застосовувати активацію двічі.** Якщо функція вже повертає `sigmoid(z)` (як `neuron_forward` тут), не обгортати результат ще одним `sigmoid()` зовні — це змінює математику, хоч тренування формально й далі "працює" (на іншій, неправильній функції).
- **Підстановка символів у похідну — легко наплутати.** Коли формула абстрактна (`z=wx+b`, шукаємо `dz/dw`), корисно спочатку перевірити на конкретних числах (`z=3w+5`, порахувати `z` при `w=1` і `w=2`, взяти різницю) — і тільки потім повертатись до букв.
- **Без активації глибина мережі не має сенсу** — будь-яка кількість лінійних шарів = один лінійний шар.
